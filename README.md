# Узнай свою планету

Мобильная игра «Макси»: старт → 8 вопросов (карточка перетаскивается в корзинку на canvas) → результат-планета → подарки с промокодом.
Обычная статика без сборки: `index.html`, `game.css`, `game.js`, `assets/`.

## Деплой
- GitHub Pages: Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
- Свой сервер (Ubuntu/Debian): скрипт `deploy.sh` ставит nginx и забирает игру из этого репозитория; повторный запуск подтягивает свежую версию.

## Метрика и «Поделиться»
- Счётчик Top.Mail.Ru (id `3814173`): код в `index.html`, цели (`startClick`, `q1Answer…q8Answer`, `resultShown`, `resultHome/Expedition/Garden/Sweet`, `giftsClick`, `promoCopy`, `bookClick`, `rulesClick`, `restartClick`, `backClick`, `shareClick`, `shareSent`, `sharePageClick` — нажали «Узнать свою планету» на странице планеты) отправляет `track()` в `game.js`.
- «Поделиться» ведёт на `p/<планета>/` — отдельную страницу: «Моя планета — название», картинка планеты (`assets/planet-<планета>-card.webp`, вырезается из большой картинки), фраза о планете и кнопка «Узнать свою планету» в игру. У страницы свои OG-теги и картинка превью `assets/share-<планета>.jpg` (1200×630). Адреса в тегах абсолютные, их домен задаётся при сборке (`SITE_URL`, по умолчанию `https://maxi-planet-game.vercel.app`); при смене домена теги нужно пересобрать (`SITE_URL=https://домен python3 build_share.py`). Страницы и вырезки собирает `build_share.py`.

## Что настраивается в `game.js`
- `QUESTIONS` — вопросы и продукты (подпись `label`, артикул `sku`, планета `planet`, фото `img`).
- `PLANETS` — тексты результатов и иллюстрация `art` для каждой планеты (сейчас у всех четырёх одна, из макета «Уют»).
- `PROMO.code` — единый промокод (сейчас `ПЛАНЕТАЕДА`); `LINKS.book` — ссылка кнопки «Подробнее о книге».
- Правила акции — окно `#rules` в `index.html`: открывается по ссылке «Правила акции» в шапке стартового экрана, текст лежит между `<!-- rules:begin -->` и `<!-- rules:end -->` (взят из Pravila_igry.docx).
- Текст про «промокод 30% … действителен до 18.02.2027» — в `index.html`, блок `.promo__text`; даты акции в правилах (п. 1.6: с 23.11.2026 по 18.02.2027) — в блоке между `rules:begin` и `rules:end`.

## Связь с мобильным приложением (WebView)

Приложение даёт в WebView глобальный JS-объект с методом `closeGame()`. Имя объекта зависит от платформы: `MaxiGame` (по ТЗ) и `AndroidInterface` (так интерфейс называется в Android с первой реализации); подходит любой из них, список имён — `BRIDGE_NAMES` в `game.js` (и в `build_share.py` для страницы шаринга). Сейчас игра использует один метод:

- `closeGame()` — закрыть игру и вернуться в приложение. Вызывается по стрелке «назад» в шапке стартового экрана, по кнопке «Выйти» в шапке экранов результата и подарков и на странице шаринга (`p/<планета>/`). Метрика `closeGameClick` уходит за 150 мс до вызова.

Кнопки видны всегда, наличие объекта проверяется в момент нажатия (он мог появиться уже после загрузки страницы). Вне приложения, где объекта нет, кнопка возвращает туда, откуда пришли (если есть `document.referrer`), а иначе ведёт на `https://maxi-retail.ru/` — адрес в `LINKS.home` (`game.js`) и в `build_share.py`. На остальных экранах стрелка работает как раньше (подарки → результат). Код — блок «выход из игры» в `game.js`.
